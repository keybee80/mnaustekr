# MňauŠtěkr

Jednoduchá aplikace pro evidenci péče o mazlíčky.

První cíl je prostý: zaznamenat krmení rychleji a pohodlněji než v Excelu.

## v0.01

- přihlášení
- domácnost
- mazlíčci
- krmiva
- záznam krmení
- hodnocení krmiva
- jednoduchá statistika: „Sní se to doma?“

## Princip

Data patří mazlíčkům. Aplikace je pouze jejich správce.

Export dat bude vždy základní funkce.

## Budoucnost

MňauŠtěkr má být od začátku připravený na více druhů mazlíčků a další typy událostí, ale v0.01 řeší pouze každodenní krmení.
